# Hardware

This folder holds the 3D-printable parts that make up SmartSpool AMS.

## Files in `stl/`

| File | Description |
|---|---|
| `smartspool-mount.stl` | The main mount that clips into the AMS 2 Pro side slits |
| `smartspool-mount.3mf` | Same file in Bambu 3MF format (preserves print settings) |

## Print settings

- Material: **PETG** (PLA works but warps if AMS drying mode is used)
- Layer height: 0.2mm
- Infill: 20% gyroid
- Walls: 3 perimeters
- Supports: none required if printed in default orientation

## Wiring diagram

See `wiring-diagram.png` (if present) or the wiring section in the firmware README.
